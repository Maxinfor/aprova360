# 🚀 APROVAÇÃO 360

Sistema de gestão de estudos para acompanhar disciplinas e progresso acadêmico.

## ✨ Funcionalidades

- ✅ Adicionar/Remover disciplinas
- ✅ Marcar como concluído
- ✅ Editar nomes
- ✅ Filtros (Todas/Pendentes/Concluídas)
- ✅ Visualização em Lista ou Grade
- ✅ Dashboard com estatísticas
- ✅ Barra de progresso
- ✅ Notificações em tempo real
- ✅ Persistência com localStorage
- ✅ Responsivo (Desktop/Tablet/Mobile)
- ✅ Atalhos de teclado
- ✅ Efeito de confetti nas conclusões

## 🎯 Atalhos de Teclado

- `Ctrl + Shift + N` → Adicionar nova disciplina
- `Ctrl + F` → Focar nos filtros
- `Esc` → Fechar modal
